# Editorial Pose Stage

## Bounded change

Only the Human Rhythm Study component and its scoped styles change. Approved homepage, technology, wellbeing architecture, desktop right-side rows, global tokens, navigation, metadata and hello@ enquiry links remain intact. There are no new dependencies or photographic bytes.

## Composition

A flat entry edge and an open cubic turn create an architectural organic aperture. Back contours disappear under its quiet light plane and reappear beyond it. The figure occupies a related aperture; the Move aperture opens above/right of the light frame to admit the extended figure. One low, partially masked foreground contour supplies depth without encircling the person. Arrive sits left; Move uses a larger diagonal occupation; Breathe is smaller and right aligned; Close settles toward the middle. Breathe and Close remove extra back contours. Mobile uses two back lines and one restrained foreground segment.

The natural-light plane uses existing bone/soft tokens only. Neutral arrival, slightly directional movement, brighter open breath and a denser warm close are changes in opacity/position, not new colour branding. Existing fabric and skin texture is retained with modest desaturation; no new grain download or heavy filter.

## Choreography

- Figure exit: 160ms opacity, a maximum 3px displacement.
- Signal reroute: 360ms; 400ms for Breathe, smoothstep, interruptible from current coordinates.
- New figure: 360ms opacity after 160ms delay (520ms total).
- Settle: 200ms translation from 400ms (600ms total).
- Light: 600ms, no recurring loop.

An uncached figure must first load. The previous image stays visible until the next has decoded; the image transition begins then, so first-use network latency can exceed the nominal 600ms. Only visited poses are loaded. Rapid input cancels/reroutes the current signal. There is no body interpolation.

Reduced motion uses immediate signal geometry, static spatial placement and 120ms figure/light opacity only. The persistent motion-off control disables transitions. No parallax, scroll capture, timer or autoplay is added.

## Mobile and accessibility

Selected label → figure/light/signal → selected copy → a two-by-two touch selector. The desktop four-row structure is unchanged. Four native buttons support hover, focus and click/tap, expose `aria-pressed`, and keep all session copy in HTML. The selected label has a polite live region. A no-JavaScript fallback restores every button's copy on mobile. Figures have descriptive alt text; decorative SVG/light is hidden from assistive technology.
